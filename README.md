# Oleh-Oleh Kopi Gayo Lhokseumawe

Website katalog produk, cerita brand, dan informasi kemitraan Oleh-Oleh Kopi Gayo di Lhokseumawe, Aceh.

## Halaman Utama

- **Beranda (`/`)**: Hero section, pengenalan brand, pilihan favorit, kutipan, dan tautan kemitraan.
- **Tentang Kami (`/tentang`)**: Cerita kopi dataran tinggi Gayo dan dedikasi petani lokal.
- **Katalog (`/katalog`)**: Pencarian dan filter kopi (Arabika, Robusta, varian kemasan, dan gilingan).
- **Detail Kopi (`/katalog/:slug`)**: Profil rasa, tingkat sangrai, pemilihan ukuran & gilingan.
- **Kemitraan (`/kemitraan`)**: Formulir kemitraan serta unduhan katalog produk PDF.
- **Jurnal (`/jurnal`)**: Artikel dan edukasi kopi Gayo.
- **Galeri (`/galeri`)**: Galeri foto suasana dan proses pengolahan kopi.
- **Kontak (`/kontak`)**: Peta lokasi toko, kontak resmi, dan integrasi WhatsApp.

## Development

Menjalankan proyek secara lokal menggunakan Bun atau Node.js / npm:

```sh
bun install # atau npm install
bun run dev # atau npm run dev
```

Untuk menjalankan unit test:

```sh
bun run test # atau npm test
```

## Tech Stack

- TanStack Start
- React 19
- TypeScript
- Tailwind CSS v4
